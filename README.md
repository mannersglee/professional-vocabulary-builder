# 专业词汇学习 Demo

使用 `/opt/anaconda3/envs/myenv/bin/python` 启动：

```bash
/opt/anaconda3/envs/myenv/bin/python vocabulary.py run
```

浏览器打开 http://127.0.0.1:5000。首页提供总词库、待复习词汇和来源词本入口。来源词本页支持卡片 / 列表视图，以及导入日期、专业方向筛选和排序。词库可按来源、领域和状态筛选；词卡内可打开联想网络。学习页按复习日期、优先级和更新时间安排词卡。

总词库中的领域筛选按一级、二级、三级逐层显示；选中上一级后才会显示下一级。点击整张词卡进入详情。学习页揭开答案后也会显示同样的词卡详情，包括释义、例句、来源和联想网络。详情页的联想网络固定在侧栏，词库总览卡片不展示网络。

顶部导航栏在所有页面固定显示。来源词本卡片对长文件名自动断行，超过三行时缩略显示，悬停可查看全名。词条详情页采用无需页面滚动的单屏布局；内容过长时可在对应信息卡内滚动查看全文。

学习页采用固定视口布局：单词本与专业方向筛选可折叠，音标始终位于单词下方，揭开答案后可选择底部固定的四档记忆状态。陌生 10 分钟后复习，模糊 1 天后复习，认识从 3 天、熟悉从 7 天起逐次延长间隔（连续记住后最多分别为 60、120 天）。旧的 New / Learning / Mastered 状态会迁移为陌生 / 模糊 / 熟悉，复习次数与日期保留。较长释义与例句可在对应信息卡内滚动查看全文。

## 添加语料

1. 点击「添加语料」，上传 PDF、DOCX 或 TXT。可选择已有专业方向，或新增多个一级 / 二级 / 三级方向，并设置词汇数量阈值。
2. 点击「生成 TXT」，页面显示文件上传与文本提取进度。完成后检查 TXT；此时仍可调整阈值并保存。
3. 下载该语料的 TXT 和专属 `SKILL.md`，手动发送给 AI，要求返回 JSON。阈值越低，SKILL 要求提取更多专业术语；实际数量取决于语料与模型。
4. 上传 AI 返回的 JSON。系统创建来源词本，将词条并入总词库，并为该来源的所有词条附上所选专业方向。

也可以直接上传 JSON。若其中的 `source_id` 不属于当前本地语料库，系统会将其作为独立来源词本导入，并保留 JSON 内的文献来源、页码和上下文；已存在的 `source_id` 仍会关联对应语料。

AI 调用仍由用户手动完成。PDF / DOCX 转换使用解析库，扫描版 PDF 需先 OCR。网页不会在启动时自动转换或导入任何测试 PDF。

## 命令行与数据

```bash
/opt/anaconda3/envs/myenv/bin/python vocabulary.py convert path/to/source.pdf
/opt/anaconda3/envs/myenv/bin/python vocabulary.py import path/to/book.json
```

每次导入创建独立词本；总词库按英文标准术语合并，保留学习记录。重复导入同一 JSON 会再次累加频次。数据存于 `data/vocabulary.db`，规范化 TXT 存于 `data/`。`GET /api/terms` 提供词汇 JSON；朗读接口暂保留为 `GET /api/pronunciation/<term_id>`。
